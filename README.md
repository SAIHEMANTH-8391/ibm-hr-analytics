# HR Analytics System – Employee Retention & Attrition 📊

This project helps HR professionals analyze employee attrition trends to identify the key factors behind retention and resignation, using real-world HR data from IBM.

## 🚀 Objective

To create an end-to-end HR analytics dashboard that:
- Identifies key drivers of employee attrition
- Helps HR make data-driven decisions to reduce turnover
- Provides interactive and visual insights using Power BI

## 📂 Dataset

- Name: IBM HR Analytics Employee Attrition Dataset
- Source: Kaggle
- File: `WA_Fn-UseC_-HR-Employee-Attrition.csv`

## 📊 Features in Power BI Dashboard

- 📈 Attrition by Age, Gender, Department, Job Role
- 💰 Salary vs Attrition Correlation
- 📚 Education vs Attrition
- 🧑‍🤝‍🧑 Men vs Women Attrition Rates
- 🕒 Years of Experience vs Attrition
- 🔍 Department-wise Attrition Rate
- 🎛️ Interactive filters (slicers) for job role, gender, education, department

## ⚙️ Technologies Used

- Power BI (Dashboard)
- Python (Data Cleaning & EDA)
- Pandas, Matplotlib, Seaborn
- Excel/CSV (Data Source)

## 🛠️ How to Run the Project

1. Open `HR_Analytics.pbix` in Power BI Desktop
2. Load the dataset from `WA_Fn-UseC_-HR-Employee-Attrition.csv`
3. View all visualizations in Power BI
4. Explore insights via slicers and filters
